# ADR 0005: Deterministic Diagnosis Before AI

- Status: Accepted
- Date: 2026-07-17

## Context

ImagePullBackOff 可能由镜像不存在、仓库网络异常或认证失败引起。仅让大模型阅读一段错误文本会产生不可重复结论，也容易把常见经验错误地表述为已观察事实。

## Decision

诊断首先由确定性规则匹配 Kubernetes 状态。规则输出分为三层：已命中的条件、可追溯证据、需要进一步验证的可能根因与建议。证据只允许来自本次采集的资源状态、关联 Event 或关联资源摘要，不允许把预设根因写成证据。

规则结果及证据通过同一数据库事务保存。AI 后续只能读取该结构化结果做解释增强，不能修改命中条件、伪造证据或直接执行修复操作。

规则 ID 包含资源类型、语义和版本，例如 `pod.image_pull_backoff.v1`。规则语义变化时新增版本，避免历史记录无法解释。

## Consequences

- 同一资源状态产生稳定、可测试的规则结果。
- 用户可以区分“已经观察到什么”和“接下来应验证什么”。
- 规则覆盖面需要逐条扩展；未命中时明确返回 `NO_RULE_MATCH`，不使用 AI 强行生成结论。
- 后续加入 AI Provider 时必须引用证据来源，并保留无 AI 的规则兜底。

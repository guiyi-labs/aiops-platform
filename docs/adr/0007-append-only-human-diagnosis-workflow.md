# ADR 0007: Append-only Human Diagnosis Workflow

- Status: Accepted
- Date: 2026-07-17

## Context

规则诊断输出描述某一观察时刻的资源状态。人工确认、处置和准确性判断发生在规则运行之后，如果直接修改摘要、证据或只保留当前状态，就无法解释历史上由谁做过什么判断，也不利于后续评估规则质量。

## Decision

规则结论与证据保持不可变。`diagnosis_records` 只更新当前状态、负责人和更新时间；每次状态变化在同一事务内追加 `diagnosis_activities`。人工准确性判断独立追加到 `diagnosis_feedback`，不改变规则 ID、摘要、根因模板或证据。

状态机显式限制合法边：open 可确认或驳回，confirmed 可解决或驳回，resolved/dismissed 可重新打开。首次状态操作自动认领给操作者。只有系统管理员和运维管理员可以修改状态或提交反馈，其他登录角色只读。

## Consequences

- 可以完整追溯状态、负责人、操作者、备注和反馈时间线。
- 并发流转通过行锁和事务串行化，非法跨级操作返回冲突而不是覆盖状态。
- 状态活动承担业务处置轨迹，但不替代平台级安全审计；后续审计服务仍需记录请求 ID、来源和授权结果。
- 反馈数据可以用于规则命中率分析和未来 AI 解释评估，但当前不自动改变规则行为。

# ADR 0012: Append-only AI Explanation Quality Feedback

- Status: Accepted
- Date: 2026-07-17

## Context

引用校验只能证明模型引用了存在的证据，不能证明解释对排障人员有帮助。只观察调用成功率和 token 用量也无法比较模型、提示词或建议质量。评价若直接改写解释、允许匿名重复投票或把自由文本暴露给所有用户，会破坏历史可追溯性并引入隐私与统计偏差。

## Decision

为每条 AI 解释增加独立、追加式质量反馈。所有已登录角色可以选择 `helpful`、`partially_helpful` 或 `not_helpful`，并附加最多 1000 字符的可选备注。数据库以 `(explanation_id, actor_user_id)` 唯一约束保证每位用户对同一解释至多评价一次；API 不提供修改和删除。

解释列表返回三档聚合计数、严格有帮助率和当前用户自己的评价。其他用户的身份与备注不随解释列表返回。全局质量接口返回总反馈数、贡献者、已评价解释数和按模型分组；有帮助率使用 `helpful / total`，不为“部分有帮助”设置主观权重。

评价提交进入统一审计，审计只记录解释 ID、操作者、结果和 HTTP 元数据，不保存备注正文。评价不触发在线学习，不修改确定性诊断、证据、解释正文、提示词或模型路由。

## Consequences

- 同一解释可以汇集不同角色的独立判断，同时避免单用户重复投票。
- 质量汇总可作为模型或提示词离线评测的输入，但样本量和参与者构成仍需人工解释。
- 用户删除后评价样本与名称快照保留，贡献者去重数不再包含已删除用户的空外键。
- 当前不支持撤回或改票；需要纠错时应通过后续带原因的管理流程扩展，而不是静默覆盖历史。

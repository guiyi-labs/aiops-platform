# 2026-07-17 User and Role Management

## Scope

- 新增系统管理员用户列表、创建和安全更新 API，以及用户管理控制台页面。
- 支持四类预置角色、显示名更新、账号启停、角色替换和活跃状态展示。
- 用户名按小写安全格式校验，初始密码至少 12 字符并以 bcrypt 摘要保存；敏感字段不进入响应或审计。
- 每个受保护请求读取数据库中的当前用户状态与角色，使停用和撤权立即作用于旧访问令牌。
- 角色变更或停用会撤销刷新会话；当前用户不能停用自己或修改自己的角色。
- 使用事务级 advisory lock 与行锁保护“至少一个活跃系统管理员”不变量。
- 用户创建和更新接入统一审计，操作代码为 `user.create` 与 `user.update`。
- 前端导航和路由同时限制系统管理员访问，用户页支持创建、编辑、启用和停用。

## Boundaries

- 暂不提供密码重置、强制首次改密、MFA、SSO/LDAP 和登录设备管理。
- 角色为平台预置代码，不支持管理员创建自定义角色或权限策略。
- 实时授权每个受保护请求增加一次用户查询，尚未引入带精确失效的授权缓存。

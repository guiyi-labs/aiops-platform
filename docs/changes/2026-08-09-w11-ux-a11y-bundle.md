## What Changed

- `frontend/src/styles/premium-ui.css`（新增，`main.ts` 引入）：
  - 顶栏强化玻璃拟态（blur + saturate + 柔和阴影）；
  - workspace-selector 悬浮上浮 + 箭头旋转；
  - 侧栏激活项蓝条 + 图标着色 + 柔和外发光；
  - 头像悬浮光环、退出按钮 hover 危险色反馈；
  - 主按钮按压缩放、卡片顶缘渐变光晕、统一 `::selection`。
- `frontend/e2e/a11y.spec.ts`（新增）：对 `/`、`/clusters`、`/topology`、
  `/posture`、`/optimization`、`/search`、`/events` 七个关键路由做
  axe-core WCAG 2A / 2AA / 2.1AA 扫描，双视口（Desktop + Mobile）断言
  无 critical/serious 违规；沿用 smoke 的 console-error=0 钩子。
- WCAG 对比度修复（axe 实测 27 类问题归零）：
  - `base.css` 把 10 个低对比 muted 灰统一为 `#5b6672`（白底 5.85:1、
    灰底 5.32:1）；
  - `console-theme.css` `--text-muted` → `#5b6672`、`--text-tertiary` →
    gray-600、`.live-indicator` → `#15803d`（4.57:1）；
  - `PostureView.vue` 严重度 chip 改用深色（危险 `#b91c1c` 5.30:1、
    警告 `#92400e` 6.37:1、信息 `#0369a1` 5.17:1、通过 `#15803d`），
    集群下拉补 `aria-label="选择集群"`（原缺失，axe critical）。
- `frontend/scripts/bundle-gate.mjs` + `pnpm bundle:gate`：构建后检查
  entry JS ≤60kB gzip、最大路由 chunk ≤32kB、全量 JS ≤310kB、
  CSS ≤70kB。CI 在 `pnpm build` 后新增 `Bundle size gate (W11)` 步骤。
- `devDependencies`：新增 `@axe-core/playwright@^4.12.1`。

## Context

## What Changed

### 新脚本 `scripts/audit-a11y-axe.mjs`
- 复用仓库内 `@axe-core/playwright` 依赖自带的 `axe.min.js`
  （`frontend/node_modules/.pnpm/axe-core@4.12.1`），经 CDP 注入 + `axe.run` 跑
  WCAG 2.x A/AA 规则。
- 双视口（Desktop/Mobile）+ 幂等鉴权登录（复用基线脚本的登录手段）。
- 控制台错误分类：
  - **app 错误**：导航/settle 阶段发生的 exception / console error（导航期先采集）。
  - **axe 诱导错误**：axe.run 强制同步布局会加宽 Vue 短暂 patch 竞态窗口
    （实测真实用户浏览 3 次独立复现均 0 错误），单独归因、不参与门禁失败判定。
  - **auth probe**：未认证 `POST /api/v1/auth/refresh` 返回 401 被 auth store
    try/catch 兜底，属预期探测，单列计数而非错误。
- 门禁：critical/serious 或 app 错误任一存在 → exit 1。

### 对比度修复（唯一 serious，`frontend/src/styles/base.css`）
- `WorkloadsView` 的 `.resource-kind-tabs button` 前景 `#64727a` 对浅灰容器
  `#e8edef` 对比度 4.15 < 4.5（AA）。改为 `var(--gray-600)`（`#4c5c61`），
  对比度提升至 5.91（AA ✓）。顺带再消除一处硬编码色（与 CSS token 收口一致）。

- Date: 2026-08-14
- Status: Complete
- Scope: 将外部平台调研得到的产品结构优点转化为 M112–M114 的正式开发路线与验收边界。

## Context

调研 `http://43.142.82.55:18088/` 后，确认其较有价值的能力集中在统一平台入口、集群健康总览、资源详情上下文、容量感知调度预览、开发工作空间状态和事件直达。与此同时，该平台存在 iframe 依赖、默认凭据暴露、直接终端/删除/YAML 编辑和前端运行时错误等实现风险，不能直接复制。

## What Changed

### 路线基线

- `docs/development-roadmap-post-m110.md`：将 M111 更新为已完成基线，登记提交、CI 和 `baseline-m111-20260814`。
- 新增“借鉴后的产品原则”：统一入口、上下文优先、容量感知但不越权、状态可见且有界、质量门禁不回退。

### M112–M114 路线

- M112 增加事故上下文驾驶舱、会话式调查、引用式 AI 摘要和解释覆盖率大盘。
- M113 增加 CPU/内存/GPU/存储/网络约束下的容量感知预览，继续坚持 dry-run 和人工确认。
- M114 增加事件驾驶舱、重复事件聚合、时间窗口、趋势和深链，并保留原始证据可追溯性。
- 增加跨里程碑“资源上下文契约”：scope、observed_at、来源、freshness 和空样本语义必须显式返回。

### 安全与整合边界

- 外部系统只提供权限校验后的深链或状态卡，不默认 iframe 嵌入，不共享默认凭据。
- 不引入任意终端、删除、YAML 编辑或直接部署链路；新写操作仍需进入受控 remediation 目录并经过 ADR 评审。

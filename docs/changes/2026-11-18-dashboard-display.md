# Dashboard Display：集中呈现集群运行态势

- Date: 2026-11-18
- Status: Complete
- Scope: 在现有系统概览中整合资源、诊断与观测图表，保留五个一级入口。

## Context

精简后的概览只有基础统计与文字，缺少集中展示资源状态和故障线索的画面。复用现有只读接口补充可视化，无需扩展后台业务模块。

## What Changed

- `frontend/src/views/DashboardView.vue`：增加关键指标、CPU/内存环形仪表、Pod 健康分布、集群节点归属拓扑、诊断处理分布、Pod 资源排行、最近诊断与警告事件；支持集群切换、30 秒自动刷新和全屏展示。全屏宽屏布局集中展示主要图表，常规布局保留明细列表。
- `frontend/src/components/DashboardTrend.vue`：单节点资源趋势，支持节点、CPU/内存和 1/6/24 小时切换；复用历史序列图表工具，展示采集覆盖及缺样状态。
- `frontend/src/views/TopologyView.vue`：从概览打开完整拓扑时沿用所选集群。
- `frontend/e2e/dashboard.spec.ts`：验证集群/指标切换、缺失指标、分页提示、全屏键盘交互、焦点返回与明暗主题可访问性。

## Verification

## Risks / Notes

- 图表区分全量资源总数、已读取资源样本与最近最多 100 条诊断；分页存在时显示提示，指标不可用时不伪造零值。
- CPU/内存水位基于有有效指标且可匹配可分配容量的节点，原始指标源时间可从仪表说明查看；历史曲线明确选择单节点。
- 拓扑连线表达集群归属，节点下 Pod 数量来自已读取样本，不表示网络通信或服务依赖。
- 全屏使用浏览器 Fullscreen API；不支持时保留扩展画布，可用退出按钮或 Escape 返回。
- 自动刷新只在页面可见、前次读取完成时执行，可手动暂停。
- 仅本地归档和提交，本次不推送远端。

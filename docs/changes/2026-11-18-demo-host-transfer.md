## Risks / Notes

- 局域网客户端访问演示主机的 `18080` 端口；演示机本机使用 `http://localhost:18080/`。应用账号沿用原控制台账号。
- 日常使用 `manage.sh`，首次部署脚本发现已有同名卷会停止，避免重复覆盖。不要执行 `docker compose down -v`，该命令会删除演示数据卷。
- 服务不再依赖开发机在线；真实集群与可选模型提供者仍需要可达。Event 为空时如实展示，不为演示填充伪造数据。
- 源应用与原数据库保持运行，未改动现有 Kubernetes 工作负载。

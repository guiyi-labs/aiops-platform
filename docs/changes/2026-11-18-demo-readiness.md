# Demo Readiness：案例演示流程、运行检查与核心交互修复

- Date: 2026-11-18
- Status: Complete
- Scope: 在五个主入口内完善实际案例演示、只读工具展示与核心功能可用性。

## Context

案例检索需要手工填写参数，无法保留更名前后的两次结果；部分资源详情、回放和可选解释降级存在交互缺陷。将现有核心能力整理为能从数据、规则、证据到案例复用连续展示的流程。

## What Changed

- 案例检索可选择当前真实案例，自动带入描述、规则与资源类型，一键执行原规则/更名规则两次实际查询，保留对照矩阵与结果快照，提供自动结论、来源证据跳转和双运行 JSON 导出；高级参数与排序细节默认折叠，修改表单后提示结果仍属于旧条件。
- 案例为空时显示积累路径；切换案例或失败时清除旧结果，案例列表刷新失败不再保留旧数据。
- 系统设置增加运行与工具页签：检查服务、集群四类采集、案例与可选 AI 状态，导出检查快照；展示共享 MCP 目录，并调用实际网关参数校验器验证合法、未声明和路径越界参数。校验绝不执行工具请求。
- MCP 目录移除运行时未装配的事故工具，保留诊断列表、诊断详情、证据回放、案例查询、案例统计和集群信息六项只读工具。Web 目录与 stdio 进程共享同一实现。
- 独立资源详情统一中文与主题样式，修复 Node 参数错位，支持完整 HPA 类型，区分未命中与请求失败，诊断结果直达证据；资源读取与事件失败隔离，相关事件按名称、类型和命名空间核对。
- 日志与脱敏清单支持中文状态、空态、重试、复制/下载与键盘访问；日志行使用真实换行，搜索仅影响显示，下载保留读取到的完整容器日志。
- 诊断原始记录独立于可选解释读取，切换详情隔离迟到响应并清理回放，支持 Escape 关闭；列表请求防止过期结果覆盖，导出标记解释读取可用性。
- 回放可用“下一步”直接开始，关闭或离开页面清理播放定时器。规则验证自动选择匹配场景，减少空白步骤。
- 修复关联案例前后端契约差异：因子使用 kind/value/evidence，证据完整度使用真实枚举；可选证据与阻塞原因缺省时仍正常显示，解决真实数据下的空白页。页面检查等待正文，避免仅顶栏标题出现就视为可用。
- 脱敏清单补齐 Node、ConfigMap、StorageClass 与 HPA 的白名单和 Kubernetes 路径，沿用敏感字段脱敏，并遮盖二进制数据与最后应用配置注解中的原始值；补充实际读取/脱敏回归，修复界面存在入口而接口返回 404。
- CLI 案例查询切换当前知识接口，增加环境令牌认证、15 秒超时和最低严重度筛选，避免旧接口持续降级到内置数据。
- 增加 [控制台演示路线](../console-demo-guide.md)，说明入口、操作和验证边界。
- API 文档、类型、权限矩阵、审计操作筛选与界面检查目录同步。

# Node and Pod inspection

- Date: 2026-11-18
- Status: Complete
- Scope: 完善立体场景内节点与 Pod 的联动查看。

## Context

原场景仅支持点击节点标签，工作负载列表仅在大屏显示前五项，并在部分尺寸隐藏。展示节点信息及其 Pod 时需要保留场景，同时直接查看资源细节。

## What Changed

- `frontend/src/components/ClusterScene.vue`：机柜和标签共用点击及键盘选中目标；节点侧栏增加版本、系统、运行时、调度状态，保留真实指标与证据入口。
- 节点 Pod 列表展示该节点全部已读取样本，支持滚动、名称/命名空间搜索、异常筛选，按健康状态优先排序；区分无数据、读取失败和筛选无结果。
- Pod 行展示状态或等待原因、容器就绪数和重启次数，展开后查看 IP、容器镜像、就绪情况及详情/日志入口；命名空间参与资源身份，避免同名 Pod 混淆。
- 常规概览、大屏、窄屏均保留 Pod 列表；切换节点或集群清空筛选和展开状态，手动操作停止自动巡览，避免讲解对象被切走。
- `frontend/e2e/spatial-cluster.spec.ts`：覆盖长列表、同名资源、异常状态、筛选、展开、真实机柜点击、切换清理以及空数据和错误状态。
- `docs/console-demo-guide.md`、`CHANGELOG.md`：更新展示路径及交付记录。

## Risks / Notes

- 列表复用概览已读取的 Pod 样本（现有接口读取上限 100），明确显示读取范围，不声称完整覆盖大型集群。绘图仍保留六节点和每节点十八 Pod 单元上限，列表独立于绘图上限。
- 未新增写接口或集群操作。缺失版本和指标明确显示未返回/暂无指标。
- 回退可使用 `compose-before-node-pods-20261118.yaml` 和保留的上一版前端镜像，静态目录备份为 `dist-before-node-pods-20261118`。

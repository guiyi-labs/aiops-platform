# Dashboard layout

- Date: 2026-11-19
- Status: Complete
- Scope: 消除概览左右卡片空白，优化场景及详情的空间分配。

## Context

节点详情与 Pod 列表在场景下方纵向排列，导致中央卡片较高；原三列网格默认拉伸同排资源、诊断卡片，产生大片空白，并推迟趋势和排行的展示位置。

## What Changed

- `frontend/src/views/DashboardView.vue`：资源水位与诊断分布组合为紧凑左栏；场景占据剩余宽度，网格按内容顶部对齐。诊断状态使用两列分布，保留所有指标和入口。
- 使用容器宽度确定断点，适应导航侧栏与不同窗口尺寸；中等宽度概况卡片并排、场景另起一行，窄屏按阅读顺序纵向排列。
- `frontend/src/components/ClusterScene.vue`：空间充足时将场景和详情并排，常规概览场景主体固定 600px，详情独立滚动。Pod 搜索与展开不再撑高整行；空间不足时仍支持纵向布局。
- 保留综合与立体大屏；立体大屏隐藏新增概况容器，沿用视口适配、场景控制与键盘退出。
- 在搜索控件局部设置深色语义变量，避免全局表单兜底样式导致暗色场景中的白色搜索框。
- `frontend/e2e/spatial-cluster.spec.ts`：增加多宽度空间关系检查，确保摘要卡片不被拉高、宽屏场景与详情并排及窄屏阅读顺序。
- 同步更新 `CHANGELOG.md`、`docs/console-demo-guide.md`。

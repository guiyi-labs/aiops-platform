# 控制台演示路线

保留五个主入口：系统概览、集群与资源、故障诊断、历史案例、系统设置。建议沿一条故障证据链展示，约 6–8 分钟。

## 开始前

打开 `/settings/tools`，点击“检查演示环境”。确认服务、集群数据和案例库的实际状态；可选 AI 未启用时，规则诊断、证据回放和案例检索仍可独立展示。检查快照可以导出。页面读取当前第一个已启用集群，其他集群在资源页切换查看。

准备一条已有诊断及其历史归档案例。案例来自已解决诊断，不需要为演示写入虚构记录。参考案例的来源诊断可以直接打开核对。

## 推荐顺序

| 步骤 | 入口 | 操作与可展示的实现 |
| --- | --- | --- |
| 1 | 系统概览 `/` | 展示集中大屏、故障分布和采集状态；解释当前统计对应的集群与时间范围。 |
| 2 | 集群与资源 `/workloads` | 选择真实集群与资源，查看状态、相关事件、指标；Pod 可查看和过滤容器日志，资源可下载脱敏清单。 |
| 3 | 故障诊断 `/diagnoses` | 打开已有记录，说明命中规则、根因候选、结构化证据与时间线；用“下一步”或播放回放，下载证据 JSON。新运行诊断应明确区分“未命中规则”和“采集失败”。 |
| 4 | 关联分析 `/diagnoses?view=correlation` | 选择关联案例，说明资源、信号链路、归因因子、变更候选与证据完整度；证据不足时展示未知或候选状态。 |
| 5 | 资源拓扑 `/diagnoses?view=topology` | 点选资源观察入口、Service、EndpointSlice、Pod 和 Deployment 之间的实际关系。 |
| 6 | 历史案例 `/cases?view=compare` | 选择真实参考案例，点击“一键演示更名前后对比”；同时保留原规则和更名规则的实际查询，比较结构化返回数及混合检索排名，导出双运行快照。 |
| 7 | 规则验证 `/diagnoses?view=validation` | 运行固定场景验证，选择一条规则，比较故障正例与近邻负例，核对输入、规则结论、证据和 Pod 优先级链；导出验证报告。 |
| 8 | 运行与工具 `/settings/tools` | 展示六项只读 MCP 工具；依次载入合法参数、未声明参数和越界路径，执行参数校验，说明工具边界。 |

检索对比默认收起高级参数和融合明细。需要解释算法时，展开“自定义检索参数”或“查看融合排序明细与计算说明”。改动参数后页面会提示当前快照仍属于上次条件，再运行才产生新结果。

## 功能与验证边界

- 采集、确定性规则、拓扑关系、结构化证据、人工处理与反馈、案例自动归档、混合检索、可选模型解释、只读工具、CLI/Web 均有对应实现；账号、集群凭据、模型接入和审计位于系统设置。
- 固定语料验证覆盖 12 条规则、38 个场景，其中包含故障正例和近邻负例。通过率代表该语料的规格一致性，不代表生产环境准确率。
- 原规则与更名规则均执行真实检索。更名只改变本次请求，不修改案例库；不保证每条参考案例都能排第一。结果显示候选池上限、向量不可用和降级状态。
- 当前词法嵌入使用文本特征；RRF 分数用于排序，不能解读为诊断置信度或通用语义理解能力。对比中关闭可选模型重排。
- MCP 页面校验参数但不执行工具，也不宣称客户端已连接。实际 stdio 网关需要独立启动 `aiops-mcp`，使用有效用户令牌，权限仍由后端检查。
- CLI 的远程案例检索使用 `aiops cases --server <API地址> --query <故障描述> -o json`，令牌通过 `AIOPS_API_TOKEN` 环境变量提供；检查输出 `mode` 是否为 `server`。请求失败会明确退回内置案例。
- AI 可用性检查读取运行状态，不会发起付费模型生成。现场生成解释取决于已配置提供者、网络和额度；调用失败时仍保留原始诊断与证据。
- 修改账号、集群接入、凭据或诊断生命周期会产生真实写入。已有记录足以完成只读演示；确需结案归档时，先说明这是实际状态变更。

## 立体集群展示

在“系统概览”选择真实集群，点击场景右上角“立体大屏”。点击“环绕”可缓慢改变视角，“巡览”每六秒切换节点；也可拖动场景或直接点击节点卡片，查看该节点 CPU、内存与 Pod 状态。“查看节点证据”可进入实际资源详情。

展示时可用“综合大屏”切回指标总览，使用“退出展示”或 Escape 返回。流光表达集群归属，Pod 单元依据已读取样本，数值与状态来自实际资源快照。
